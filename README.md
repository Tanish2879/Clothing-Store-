# Clothing Store

A responsive clothing store landing page built using HTML5, CSS3 and Vanilla JavaScript.

## Features
- Responsive design
- Product listing using DummyJSON API
- Dark/Light theme with LocalStorage
- Product search
- Contact form
- Semantic HTML
- 404 Page

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript (ES6)

## Project Structure

```
assets/
css/
js/
pages/
```

## Pages
- Clothing Store/pages/404.html
- Clothing Store/pages/products.html
- Clothing Store/pages/index.html
